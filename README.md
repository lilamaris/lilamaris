# lilamaris

내 서버에 직접 얹어 쓸 도구를 만들며, 백엔드 등뼈를 주로 깁니다.
지금은 [lilserve](https://github.com/lilamaris/lilserve) 모노레포 위에 좌석 예약·게시판 서비스 [lilboard](https://github.com/lilamaris/lilboard)를 얹는 중입니다.

- 🔭 **Making** — lilserve · lilboard (Java · Spring Boot · Gradle Kotlin DSL · PostgreSQL)
- 🌱 **Learning** — Rust · Astro · Ansible, 그리고 C로 DB를 맨손으로 ([csqlite](https://github.com/lilamaris/csqlite))
- 🏠 **Self-hosting** — SBC 한 대에 넣은 설정을 통째로 커밋해 둡니다 ([lilamaris-infra](https://github.com/lilamaris/lilamaris-infra))
- ✍️ **Writing** — [blog.lilamaris.kr](https://blog.lilamaris.kr) · [articles](https://github.com/lilamaris/articles)
